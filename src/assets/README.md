# Images

**Your photo goes here.**

1. **Remove the photo's location first.** Phones and cameras store the GPS position where a photo
   was taken, and this repository is public. The easiest way is to take a **screenshot** of the photo
   and crop it: screenshots carry no location. Or remove it directly:
   - Windows: right-click the file > Properties > Details > *Remove Properties and Personal Information*.
   - Mac: open it in Preview > Tools > Show Inspector > the (i) tab > GPS > *Remove Location Info*.
   - iPhone: in Photos, tap Share > Options, turn Location off, then save the shared copy.
   - Android: use the screenshot method, which works on every phone.
2. On GitHub, open this folder, click **Add file > Upload files**, drag the photo in,
   then click **Commit changes**. The site rebuilds in about three minutes.

Good to know:

- Any file name works if it is the only image here. Naming it `photo.jpg` is safest.
- Use JPG or PNG. iPhone HEIC photos do not work: share or export them as JPG first.
  A file ending in `.jfif` is a JPEG: rename it to end in `.jpg`.
- A square or portrait photo with your face near the middle works best. The site crops it
  to a square around your face and makes small, fast versions automatically, so a large
  original is fine (GitHub accepts up to 25 MB per file).
- If the photo still holds its location, the automatic privacy check stops the site from
  updating and says so in the **Actions** tab. Replace the photo and delete the old file.
  Deleting a file does not remove it from the repository's history, so remove the location first.
- To change the photo later, upload the new one with the same name and it replaces the old one.

Project cover images go in `src/assets/projects/`, so they are never mistaken for your photo.
